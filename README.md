# 음악 연구소 탈출: 사라진 으뜸음

6학년 음악 3단원 복습용 개별 방탈출 게임입니다. (음이름·계이름, 바장조 계이름, 음표·쉼표 박 수, 조표 판별)

- 게임 화면과 이미지는 GitHub Pages에서 제공합니다.
- Apps Script는 POST 요청으로 기록을 받아 점수를 다시 계산한 뒤 구글 시트에 한 줄로 기록합니다.
- 자물쇠 비밀번호는 소스에 평문으로 두지 않고 해시로만 비교합니다.

## 파일 구조

- `index.html` — GitHub Pages 게임 본체 (단일 파일, 음표·오선은 SVG로 그림)
- `assets/img` — 장면·캐릭터 WebP 이미지

`Code.gs`, 기획서, 테스트·해시 생성 스크립트는 로컬에만 보관하며 `.gitignore`로 공개 저장소에서 제외합니다.

## 로컬 목 모드

`index.html` 상단의 `SUBMIT_URL`이 비어 있으면 서버 호출 없이 가짜 응답으로 결말 화면까지 진행합니다.

```powershell
python -m http.server 8765
```

브라우저에서 `http://127.0.0.1:8765`를 엽니다. 저장된 진행 상황을 지우려면 주소 끝에 `?reset`을 붙여 엽니다.

## 배포

1. 새 구글 시트에서 **확장 프로그램 → Apps Script**를 열고 `Code.gs`를 붙여넣습니다.
2. **배포 → 새 배포 → 웹 앱**에서 실행 사용자는 **나**, 액세스 권한은 **모든 사용자**로 설정합니다.
3. 생성된 `/exec` 웹앱 주소를 `index.html` 상단의 `SUBMIT_URL`에 입력하고 GitHub에 다시 푸시합니다.
4. GitHub 저장소의 **Settings → Pages**에서 `main` 브랜치 루트를 배포 소스로 설정합니다.
5. 실제 제출 1건을 보내 `결과` 시트의 헤더와 점수를 확인합니다.

POST 본문은 `text/plain;charset=utf-8`로 전송하며 내용은 JSON입니다. 전송 실패 시 제출 데이터가 `localStorage`에 남고 **다시 보내기**를 사용할 수 있습니다.
